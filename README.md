## المشاريع

### 1. منصة متكاملة لتدريب ونشر نماذج معالجة اللغة العربية (NLP)
*   **الوصف:** منصة شاملة ومستقلة قمت بتطويرها بالكامل لتسهيل دورة حياة نماذج الذكاء الاصطناعي المتخصصة في اللغة العربية، بدءاً من معالجة البيانات، مروراً بالتدريب والتقييم، وانتهاءً بالنشر كخدمات API جاهزة للاستخدام.
*   **التقنيات الأساسية:** Python, PyTorch, Hugging Face Transformers, Flask, Docker, AraBERT, CAMeL Tools, Scikit-learn, Pandas.
*   **الوظائف الرئيسية:** التدريب المخصص (Fine-tuning) باستخدام نماذج لغوية عربية مدربة مسبقاً، دعم مهام متعددة مثل تصنيف المشاعر والمحتوى وكشف الرسائل المزعجة، والنشر الآلي للنماذج المدربة كخدمات ويب.
*   **دوري:** تطوير المشروع بشكل فردي بالكامل، مما شمل التصميم المعماري، كتابة الكود، تدريب النماذج، والتغلب على التحديات الخاصة بمعالجة اللغة العربية.

### 2. نظام المراقبة بالكاميرا الذكية
*   **الوصف:** نظام مراقبة ذكي متقدم يعتمد على تحليل الفيديو في الوقت الفعلي لأتمتة مهام المراقبة والأمان. يهدف النظام إلى توفير تحليل استباقي للأحداث بدلاً من المراقبة السلبية التقليدية.
*   **التقنيات المستخدمة:** Python, YOLO, OpenCV, نماذج التعرف على الوجوه.
*   **الميزات الرئيسية:** الكشف والتصنيف الفعال للكائنات والأشخاص، التحليل السلوكي لتحديد وتسجيل الأحداث المعقدة (مثل الحوادث أو المشاجرات)، استخدام بصمة الوجه، وإطلاق تنبيهات أو تنفيذ مهام محددة مسبقاً عند اكتشاف كائن أو حدث معين.
*   **دوري:** عملت ضمن فريق ثنائي، وتركزت مسؤولياتي على تطوير الواجهات البصرية (Visual Interfaces) وإدارة الخادم (Server-side logic).

### 3. تطبيق أندرويد العين الذكية
*   **الوصف:** تطبيق أندرويد متكامل يهدف إلى تمكين الآباء من ممارسة رقابة شاملة وفعالة على أجهزة أطفالهم لضمان سلامتهم الرقمية.
*   **التقنيات المستخدمة:** Java, Android Studio, Google Firebase.
*   **الميزات الرئيسية:** تتبع ورصد وعرض الموقع، التحكم بوقت الاستخدام لكل تطبيق، التحكم باستخدام البيانات، مراقبة الدردشات من أي تطبيق، مراقبة واختيار المحتوى، اكتشاف الكلمات البذيئة أو التي يختارها المشرف.
*   **دوري:** تطوير التطبيق بشكل كامل ومستقل، بدءاً من التصميم والتكويد وحتى التكامل مع خدمات Firebase.

### 4. نظام التشفير
*   **الوصف:** نظام تشفير متقدم يدعم مجموعة واسعة من خوارزميات التشفير المتماثل وغير المتماثل والبعد الكمي، بالإضافة إلى اشتقاق المفاتيح والتجزئة. يوفر النظام أكثر من 20 خوارزمية تشفير ويدعم تقنية التشفير من طرف إلى طرف (End-to-End Encryption) بين طرفين أو أكثر. كما يتميز بقدرته على اكتشاف الاختراقات والانتحالات والإنكار المعقول، وإخفاء البيانات داخل الصور (Steganography)، وحذف البيانات بشكل آمن.
*   **التقنيات المستخدمة:** Python, Cryptography libraries (e.g., PyCryptodome, M2Crypto), Network protocols (e.g., TLS/SSL).
*   **دوري:** تطوير النظام بشكل كامل، بما في ذلك تصميم الخوارزميات، تنفيذها، واختبارها لضمان الأمان والفعالية.

### 5. منصة Django للمبرمجين
*   **الوصف:** منصة ويب متكاملة مبنية باستخدام Django تقدم مجموعة واسعة من المزايا للمبرمجين، بما في ذلك إدارة المهام، أدوات العمل الجماعي، التواصل والمناقشات، مراقبة تغييرات الـ APIs، دعم المساعدين بالذكاء الاصطناعي، الاطلاع على آخر التحديثات التقنية من مصادر متجددة، محرك بحث يجمع النتائج من جميع المنصات، دعم المستودعات والمكتبات، وتوفير المصادقة المباشرة مع GitHub و Google Drive، بالإضافة إلى بيئة تطوير متكاملة قائمة على الويب.
*   **التقنيات المستخدمة:** Python, Django, HTML, CSS, JavaScript, PostgreSQL (مثال لقاعدة بيانات SQL), MongoDB (مثال لقاعدة بيانات NoSQL), REST APIs.
*   **دوري:** تصميم وتطوير الواجهة الخلفية والواجهة الأمامية للمنصة، وتكامل الخدمات الخارجية، وإدارة قواعد البيانات.

### 6. مشروع شات بوت RGA
*   **الوصف:** شات بوت يعتمد على تقنية RGA (Retrieval-Augmented Generation) قادر على التعامل مع مختلف أنواع البيانات وتقديم استجابات دقيقة ومفيدة.
*   **التقنيات المستخدمة:** Python, Hugging Face Transformers, LangChain, Vector Databases (e.g., FAISS, Pinecone).
*   **دوري:** بناء وتدريب نموذج الشات بوت، وتكامل مصادر البيانات المتنوعة، وتحسين أداء الاستجابات.

### 7. مشروع تصنيف إشارات اليد (لترجمة إشارات البكم)
*   **الوصف:** مشروع يهدف إلى تصنيف إشارات اليد لترجمة إشارات البكم، مما يسهل التواصل مع مجتمع الصم والبكم.
*   **التقنيات المستخدمة:** Python, OpenCV, TensorFlow/PyTorch, MediaPipe.
*   **دوري:** جمع البيانات، تدريب نماذج التعلم العميق لتصنيف إشارات اليد، وتطوير واجهة المستخدم.

### 8. مكتبات إدارة مشاريع Django وتشفير قواعد البيانات
*   **الوصف:** مجموعة من المكتبات التي تساعد في إدارة مشاريع Django من ناحية الواجهة الخلفية (Backend) والواجهة الأمامية (Frontend)، بالإضافة إلى مكتبة لتشفير قواعد بيانات Django.
*   **التقنيات المستخدمة:** Python, Django.
*   **دوري:** تصميم وتطوير المكتبات، وتوفير حلول لإدارة المشاريع وتشفير البيانات.

### 9. مكتبة هياكل البيانات
*   **الوصف:** مكتبة توفر جميع أشكال هياكل البيانات الشائعة.
*   **التقنيات المستخدمة:** Python.
*   **دوري:** تصميم وتنفيذ هياكل البيانات المختلفة، وكتابة الاختبارات لضمان صحتها وكفاءتها.
